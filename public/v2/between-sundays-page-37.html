What Bread Does

Bread is not impressive because it is rare. Bread matters because it meets the body where the body actually is: hungry, tired, awake again, still here.

This month's table note is simple: make one meal that does not need to be photographed. Eat it slowly. Share it if someone is close enough to ask.
